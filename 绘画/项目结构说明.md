# 项目结构说明（深雪 ~miyuki~）

> 本文件放在「绘画」文件夹，与总流程图、流程通解放在一起，供对照阅读：
> 看流程图理解**运行时数据怎么流**，看本文件理解**代码和材料放在哪**。
> 更新日期：2026-09-15（目录重组版）

## 一、项目是什么

《深雪 ~miyuki~》：雪国开放世界 GALGAME。玩家扮演修二在雪国小镇自由行动，深雪等 NPC 由 LLM Agent 驱动（人设卡 + 记忆检索 + 知识边界 + 护栏校验），导演层用 P0~P10 剧情吸引子保证叙事骨架。技术栈：Python FastAPI（服务端引擎）+ 原生 HTML/CSS/JS（前端）+ 智谱 GLM / DeepSeek（可插拔 LLM）。

## 三、game/ 目录结构与五层架构的对应

```
game/
├── server/                    # ── 服务端引擎（五层架构）──
│   ├── world/world.py         # 世界层：事实库·场景图·知识库·关系矩阵·事件总线
│   ├── agents/
│   │   ├── personas.py        # 人设卡（静态 system prompt + 立绘清单）
│   │   ├── guardrails.py      # 护栏层：风格校验器 + 谜团锁 + 正典白名单
│   │   ├── rule_engine.py     # 规则引擎兜底（LLM 不可用时游戏仍可玩）
│   │   └── llm.py             # 可插拔 LLM 适配层（现场拼装 prompt）
│   ├── director/
│   │   ├── director.py        # 导演层：剧情吸引子 P0~P10 + 叙事压力
│   │   └── gossip.py          # 八卦传播引擎（性格过滤器·走样·后果回流）
│   ├── scenes/script.py       # 剧本数据：P0~P10 全节点（正典台词+旁白+选项）
│   ├── engine.py              # 运行时：场景推进·幕间自由行动·存档·事件溯源
│   └── app.py                 # FastAPI：REST API + 静态托管（/assets 与 /web）
├── web/                       # ── 表现层：前端 galgame 界面（原生 HTML/CSS/JS）──
│   ├── index.html / main.js / style.css   # 游戏本体界面
│   ├── flow.html              # 六张 Mermaid 流程图（在线版总流程图）
│   ├── code.html / docs.html / playthrough.html   # 代码结构全解 / 画布总览 / 通关实录
│   └── vendor/mermaid.min.js  # Mermaid 离线依赖
├── assets/                    # ── 素材层：只放可替换的美术与音频（见 assets/README.md）──
│   ├── backgrounds/           # 12 张场景背景图 1280×720 PNG
│   ├── sprites/               # 10 个角色立绘 SVG（深雪×5 表情等）
│   ├── bgm/                   # 6 首程序化合成 BGM（m4a）
│   └── ui/                    # 名牌底、雪花角饰
├── tools/                     # ── 素材生成脚本（代码，不属于素材）──
│   ├── _tools.py              # 美术工具库（渐变/山峦/雪/光晕）
│   ├── gen_backgrounds.py     # 重新生成 backgrounds/
│   ├── gen_sprites.py         # 重新生成 sprites/ 与 ui/
│   └── gen_music.py           # 重新合成 bgm/
├── tests/                     # ── 质量层 ──
│   ├── test_branching.py      # 多结局收束测试（路由穷举 + 五线实机通关）
│   ├── test_consistency.py    # 32 项一致性回归（人物圣经自检的自动化版）
│   ├── test_llm.py            # LLM 真实连通性（会耗 API 额度，勿放周期任务）
│   ├── e2e_playthrough.py     # 自动通关 P1→P0（离线模式，272 步）
│   └── capture_playthrough.py # 采集真实通关轨迹（生成 playthrough.html 数据）
├── docs/                      # 项目过程文档
│   ├── QA_REPORT.md           # 验收报告（含已知问题清单）
│   └── night_notes.md         # 监督/值守日志（bug 修复史）
├── supervisor.py              # 监督者：健康探测·自动重启·周期回归
├── llm.json                   # LLM 配置（key/model；删除即回落规则引擎）
├── README.md                  # 运行说明与玩法
├── saves/                     # 存档（运行时数据：JSON 快照 + 事件溯源 jsonl）
└── logs/                      # 运行日志（access/supervisor，可随时清空）
```

## 四、一次请求的通路（配合流程图看）

浏览器（web/main.js）→ FastAPI（server/app.py）→ 引擎（engine.py：推进节拍/幕间行动）→ 导演层决定剧情节点 → 角色 Agent（personas + llm.py 现场拼装 prompt）→ 护栏校验（guardrails）→ 不合格回落规则引擎（rule_engine）→ 世界层记账（world.py + gossip）→ 帧数据回前端渲染（背景/立绘/BGM 按 assets/ 文件名装配）。

## 五、常用命令

```bash
cd game
python3 -m uvicorn server.app:app --host 127.0.0.1 --port 8300   # 启动（http://127.0.0.1:8300）
python3 tests/test_consistency.py    # 一致性回归 32 项
python3 tests/e2e_playthrough.py     # 自动通关回归（需服务器已启动）
python3 supervisor.py --once         # 健康探测 + 自动重启 + 全量回归
```

## 六、后期替换素材的入口

1. **生图**：照《设计文档/AI绘图提示词.md》的成品提示词出图 → 按 `game/assets/README.md` 的规则覆盖同名文件（立绘换 PNG 需同步改 `server/agents/personas.py` 的文件名后缀）。
2. **流程图**：本文件夹的《游戏流程架构与流程通路.html》是总流程图与流程通解的母本；`game/web/flow.html` 是其在线版（六张 Mermaid 图，服务器 /flow.html 可看）。
3. **多结局**：游戏已从单一结局升级为「三轴·四结局」分支结构（2026-09-16），设计与阈值见《设计文档/多结局分支设计.md》，全景树状图见本文件夹《剧情分支树.html》。
4. **AI 素材**：`Gemini 绘图/` 是当前唯一绘图源（接入管线 tools/integrate_art.py 从该目录读取）；`gpt 版绘图/` 仅存档 GPT 原始图。
