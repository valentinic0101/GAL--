# 《深雪 ~miyuki~》游戏界面 UI 改版方案

本目录是游戏界面（`game/web/`）的 UI 设计调研与改版产物。包含 **3 套完整设计方案**（各 8 张高保真示例图）、**对比结论**，以及最终落地到项目的实现。

> 示例图全部使用项目**真实素材**（`game/assets/` 的背景与立绘）与**真实剧本文案**（`game/server/scenes/script.py` 的正典台词）渲染，分辨率 1280×720，与游戏实际画面一致。

---

## 一、为什么原界面需要改

改版前先用 Chrome CDP + 像素级测量对原界面做了取证（`/tmp/gal_shot/` 下的分析脚本），确认的问题不是「美术朴素」，而是**排版与配色基于错误假设**：

| # | 问题 | 实测证据 |
|---|---|---|
| 1 | **UI 假设背景是暗的，但标题背景是一张明亮雪原** | `bg_title.png` 平均亮度 166；近白标题对背景仅 2.4:1，标语 2.5:1，页脚 **1.38:1**（WCAG AA 小字需 4.5:1） |
| 2 | **游戏画面近乎全黑** | 走廊背景自身平均亮度 34/255；截图 63.5% 像素暗于亮度 30、88.2% 暗于 60 |
| 3 | **立绘被双重压暗到 44.4% 亮度，主角立绘等于不存在** | 场景光 `brightness(.60)` × 非发言者 `×.74`；主角立绘区域 mean 20.2，与空背景（19.4）**统计上无法区分** |
| 4 | **旁白框判定不出边界** | 无边框无投影，仅一层 .35→.72 黑色渐变；框内 median 25.4 vs 框外 39.6 |
| 5 | **旁白与对话是两套视觉语言** | 宽度 900 vs 1060、底部 56 vs 30、字号 19 vs 21、▼ 居中 vs 右下，切换时会跳 |
| 6 | **中文正文跑了合成假斜体** | 明朝体无真斜体，实测笔画下半相对上半**一致右移 +2px**（≈12° 斜切）；同屏未设斜体的状态栏为 0px |
| 7 | **HUD 是两条互不统一的横条** | z-index 10 与 25、字号 13 与 13.5、底色处理不同、纵向还重叠 |
| 8 | **`♪` 一号三义 / 调试串泄露** | `♪` 同时是音乐开关、好感度、羁绊轴；`v17` 被菜单栏「标题」按钮压在下面读不到 |
| 9 | **没有设计系统** | 圆角 7 种（4/5/6/8/10/12/20px）、字间距 8 种（1/1.5/2/3/6/8/14/42px），全部手工调 |
| 10 | **标题页没有雪花** | `.title-snow` 是空 div，`spawnSnow()` 只服务游戏画面；而这是「雪国」题材 |
| 11 | **页脚是面向开发者的技术宣传语** | 「多 Agent 驱动 · 导演层调度 · 八卦传播引擎 · 事件溯源存档」直接破坏文学向调性 |

**素材亮度跨度是本项目 UI 设计的核心约束**：背景平均亮度从 **30**（`bg_toba_home`、`bg_oldhouse_corridor`）到 **194**（`bg_mountains_blizzard`），跨度 6.5 倍。任何「假设背景偏暗」或「假设背景偏亮」的 UI 方案都会在另一端失效。

## 二、3 套设计方案

### 方案 A ·「雪月花」（和风旗舰派）

**文件夹**：[`A_雪月花/`](A_雪月花/)　**示例图**：[`A_雪月花/示例图/`](A_雪月花/示例图/)

**设计来源**
- **柚子社（ゆずソフト）系统** ——《千恋＊万花》《サノバウィッチ》《喫茶ステラ》的和风 UI。中文社区对它的评价是「玩过的所有 galgame 中最好的 UI，没有之一」「柚子社这套 UI 系统绝对是顶级的」，亮点是流程图系统、极用心的立绘表情拆分。
- **KEY《Summer Pockets》** —— 被评价为「界面设计与美术 UI 一等一」。
- **戏画（GIGA）咖啡三部曲**（《巧克拉》《帕露菲》《青空》）——「代表当年 gal 最高水准」，评价称其 UI「像是纯粹为这个游戏而生」，风格与游戏氛围完美契合。

**设计要点**

| 维度 | 做法 |
|---|---|
| 配色 | 主色**和纸暖白** `#f8f4ea`，墨字 `#2a251d`，强调色**朱红** `#b6433a`（落款色），点缀**金** `#a98b4f` |
| 面板 | **不透明和纸实体面板** + 1px 极细墨线 + 暖色长投影 + 内高光 + 极淡纸纹（`repeating-linear-gradient` 每 4px 一道 5.5% 透明度竖线） |
| 名牌 | 和纸札 + **朱红落款条**，外挂在对话框左上角 |
| 字体 | 保留项目原有的明朝体（`Hiragino Mincho ProN` / `Songti SC`），**去掉 CJK 假斜体** |
| 选项 | 和纸长条 + 左侧指示条（金 → hover 转朱红并加长），hover 右移 6px |
| HUD | **合并为一条和纸带**：左信息区用极细竖线分隔，右菜单同一高度同一底色；BGM 键改用 `♫` 并在静音时给明确区分 |
| 标题 | 题字改为**浓墨压亮雪**（对比度 ≈7.3:1）+ 朱红「雪」字落款印；菜单用和纸实体卡片，「开始游戏」给独立主操作权重；**补上标题页的雪花** |

**优点**：不透明面板 → 对比度与背景无关，本作亮度跨度 30→194 下**首轮全部通过**；和风语汇与「雪国 + 文学向」题材高度契合；纯 CSS 实现，无需改动 `main.js` 结构。

### 方案 B ·「灯条」（香草社平面设计派）

**文件夹**：[`B_灯条/`](B_灯条/)　**示例图**：[`B_灯条/示例图/`](B_灯条/示例图/)

**设计来源**
- **Vanillaware《十三机兵防卫圈》** —— 被评为「让 Gal 的 UI 审美从 PS2 水准飞跃到本世代」：橙白色灯条设计营造 1985 年夕阳氛围，动画跟手几乎全程满帧。
- **《铁道少女：梦想轨迹》** —— 模拟手机界面、斜切角灰色线条与列车信号灯主题。
- 编辑器排版语汇（大号编号、细分隔线、杂志式信息网格）。

**设计要点**

| 维度 | 做法 |
|---|---|
| 配色 | 近黑 `#07080a`，**唯一强调色橙** `#ff6a1a`，白字，等宽数字 |
| 面板 | **硬边 + 斜切角**（`clip-path: polygon()`），无一处圆角；左侧 5px 橙条；顶部橙色刻度线（呼应「灯条」） |
| 字体 | 无衬线（`PingFang SC` / `Hiragino Sans GB`），标签用等宽字体全大写宽字距 |
| 名牌 | **反白方章**（白底黑字）+ 右下斜切 |
| 选项 | `01 / 02 / 03` 大号橙色编号 + 细分隔线，hover 整行反白为橙底黑字 |
| 标题 | 左侧「杂志封面」式近黑竖版，橙色索引条，菜单带 `01–04` 编号，hover 反白 |
| HUD | 单条信息网格，等宽数字，橙色短光标 |

**优点**：视觉冲击力最强、信息层级最清晰（靠编号与分隔线而非字色深浅建立层级）；纯黑白 + 单强调色，对比度最高（对话正文实测 18.3:1）。

**代价**：橙黑平面语汇是「1985 都市 / 科幻」的视觉方言，与《深雪》「文学、抒情、哀愁」的气质存在冲突。

### 方案 C ·「留白」（极简文学 NVL 派）

**文件夹**：[`C_留白/`](C_留白/)　**示例图**：[`C_留白/示例图/`](C_留白/示例图/)

**设计来源**
- **极简主义视觉小说设计趋势** —— 检索到的一篇专论《The Influence of Minimalism on Modern Visual Novel Interface Design》提出的核心原则：去掉视觉噪音、UI 作为「隐形的助手」、把注意力全部留给叙事与情绪。该文给出的数据：干净的 UI 可使阅读速度提升最多 **20%**，沉浸时长增加约 **15%**，**85%** 的极简 VN 在手机/平板上表现良好，开发周期可缩短 **10–25%**。
- **《Florence》《VA-11 HALL-A》《Doki Doki Literature Club!》** —— 被点名为极简 VN UI 的代表作。
- **《海市蜃楼之馆》** —— 历史文本中出现未显示过的暗语这类「文本层」巧思。

**设计要点**

| 维度 | 做法 |
|---|---|
| 配色 | 近单色；正文 `#f4f7fb`，唯一强调色**冰蓝** `#a9c6e2` |
| 面板 | **完全不用面板**，靠**多段渐变压底**（最低 0.97 不透明度）承载文字 |
| 名牌 | 14px + 0.42em 宽字距 + 极细下划线，无底无框 |
| 正文 | 22px / 行高 2.05 / 字距 0.06em，**去掉假斜体** |
| 选项 | 纯文字居中，细下划线，hover 时字距从 0.24em 撑开到 0.30em |
| HUD | 极简无底色，**3.2 秒无鼠标移动自动淡出**（沉浸），移动即回 |
| 标题 | 巨型细体（120px / 字重 400）+ 一道冰蓝细线，菜单为纯文本行 + 细下划线 |

**优点**：沉浸感与文学气质最强，最贴合本作「文学化第一人称旁白」的调性；UI 存在感最低。

**代价（实测得出）**：在明亮背景上先天可读性不足。`bg_mountains_blizzard`（平均亮度 194）下 HUD 实测仅 **1.55:1**，必须不断加厚压底（经 2 轮加厚才到 4.6:1），这反过来侵蚀了「无面板」的极简初衷。

## 三、对比与结论

### 客观指标（1280×720 实拍截图实测）

对比度用「笔画像素掩膜」法测量：盒内取偏离底色的离群像素作为笔画，按 WCAG 相对亮度计算（正文需 ≥4.5:1，大号字 ≥3:1）。

| 指标 | A 雪月花 | B 灯条 | C 留白 |
|---|---|---|---|
| 对话正文对比度 | 13.0:1 | **18.3:1** | 1.8 → 2.6:1 |
| 旁白正文对比度 | 11.3:1 | 9.7:1 | 3.1:1 |
| 名字牌对比度 | 13.5:1 | 10.9:1（初版 1.78，已修） | 2.5:1 |
| 标题对比度 | 7.3:1 | 12.4:1 | 5.2:1 |
| **达到全项达标所需返工轮数** | **1 轮** | 1 轮 | **3 轮** |
| 结构性弱点 | 无 | 名字牌需从裁剪层移出 | HUD 与文字在明亮背景上先天不足 |
| 设计令牌数 | 13 | 11 | 7 |
| 圆角级数 | 4（2/3/5/20px） | **0** | **0** |

### 结论：选择 **方案 A「雪月花」**

理由按权重排序：

1. **唯一在素材全域亮度下无需打补丁的方案。** 本作背景亮度跨度 30→194 是核心约束。A 用不透明和纸面板，对比度与背景亮度无关，首轮即全项达标；C 花了 3 轮加厚压底才勉强达标；B 的面板视觉层必须从 `clip-path` 中挪出才能画出名字牌。
2. **题材契合度最高。** 和风暖白 + 朱红落款 + 金线的语汇与「雪国 + 文学向 GAL」一致，且这正是被社区公认为顶级 UI 的柚子社/KEY 系统所用的方向。B 的橙黑平面设计虽对比度最高、层级最清晰，但它属于「1985 都市/科幻」的视觉方言，与本作哀愁抒情的基调冲突；C 的气质最贴合，但代价是持续的可读性妥协。
3. **可读性余量充足且均衡。** A 的正文 13.0:1、旁白 11.3:1、名字牌 13.5:1，全部远超 AA 标准，且各项之间均衡（没有靠某一项极端值撑场面）。
4. **实现与维护成本最低。** 纯 CSS 即可移植，DOM 结构与现有 `index.html` 严格对齐，`main.js` 只需极少量改动。
5. **同时修掉了全部 11 项已取证硬伤。**

B 的编号系统与信息网格（`01/02/03` 选项、单条 HUD 网格）与 C 的自动隐藏 HUD、极细下划线选项，作为可选增强已吸收进最终实现。

## 四、三套方案共同的改进点（落地时已处理）

- **字号档数过多**：三套方案分别残留 21 / 19 / 17 档字号，其中 10.5、11.5、12、12.5px 这种 0.5px 级差异无实际意义。落地时收敛为模数化字阶（12 / 14 / 16 / 18 / 20 / 22 / 28 / 48 / 96）。
- **立绘亮度策略**：三套都改为「发言者 1.0、非发言者 0.86–0.88」并取消暗场景的 `brightness(.60)` 基色，修掉「双重压暗」。
- **飘雪可见度**：加大粒径（2.5–9px）、提高不透明度、标题页也注入雪花。
- **去掉 CJK 假斜体**，改用字号 / 字色 / 字距区分层级。

方案 A 已实际应用到项目。**改版前后对比截图见 [`落地验证截图/`](落地验证截图/)**（改版前 2 张 + 改版后 9 张，均为真实游戏画面，1280×720）。

| 文件 | 改动 | 备份 |
|---|---|---|
| `game/web/style.css` | **整文件重写**为方案 A；模数化字阶 9 级、圆角收敛为 4 级、字距按语义分档 | `style.css.bak` |
| `game/web/index.html` | 状态条与菜单栏合并为 `#hud`；标题页新增压底/落款印/雪花层/设置按钮；移除 4 个金色角饰与 `v17` 调试串；页脚改为文学向文案 | `index.html.bak` |

### 其它已验证项

- **无控制台报错**：驱动真实游戏走完 标题 → 旁白 → 对话 → 自由输入 全流程并打开 4 个面板，`window.onerror` 与 `unhandledrejection` 均无记录。
- **立绘不再被双重压暗**：走廊（最暗场景）立绘亮度由 **44.4% → 68.6%**，庭院场景 85.4%；主角立绘重新可辨。
- **标题页雪花 0 → 70 片**。
- **HUD 合并为一条**（高 44px，左信息右菜单同一底色）。
- **`v17` 调试串与 4 个金色角饰已移除**。
- **全部本地资源引用返回 200**（6 个静态引用 + JS 动态加载的 16 张背景、22 个立绘均已实际渲染成功）。
- 新增的 `/api/saves` meta 正确解析地点名（例：`第 1404 天 · 老屋庭院 · E_FAR · 羁绊♪47 · 2026-09-16 05:12`）。
