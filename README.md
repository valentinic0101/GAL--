# 深雪 ~miyuki~ · 雪国开放世界 GALGAME

> 她一直在等，我一直在逃，雪一直落在两人之间。

文艺系日式视觉小说（GAL）。玩家扮演修二回到雪国故乡，与深雪相遇；NPC 由 LLM Agent 驱动，
导演层用 P0~P10 剧情吸引子保证叙事骨架，三轴（羁绊 / 山之念 / 现世）通向四个结局。
技术栈：Python FastAPI（服务端引擎）+ 原生 HTML/CSS/JS（前端，无框架无构建）+ 智谱 GLM（可插拔，失效回落规则引擎）。

---

## 这个仓库分两棵树

| 目录 | 是什么 | 运行游戏需要吗 |
|---|---|---|
| **`game/`** | **游戏本体**：引擎、前端、素材、测试、开发脚本。自包含，可独立运行。 | **需要** |
| **`资料/`** | **项目资料**：剧本原稿、设定、生图源文件、论文笔记、评审与过程记录、UI 改版方案。 | 不需要 |

分开的理由：`game/` 是「跑起来要用的」，`资料/` 是「做这个游戏时用过和产出的」。
两者体量与改动频率都不一样（资料里有 100MB 级的生图源文件与实机截图），混在一起会让「哪些文件不能删」变得不可判断。

```
GAL项目/
├── README.md          ← 本文件
├── .gitignore         ← 忽略运行时产物与本机环境（存档/日志/测试报告/venv）
├── game/              ← 游戏本体（启动方式见 game/README.md）
└── 资料/              ← 项目资料（索引见 资料/README.md）
```

## 怎么玩

双击 `game/启动游戏.command`（macOS）或 `game/启动游戏.bat`（Windows）——会起服务并自动打开浏览器。
也可以在命令行里 `cd game && python3 -m uvicorn server.app:app --port 8300`，然后访问 <http://127.0.0.1:8300>。

停止：双击同目录的「停止游戏」。完整说明（含动作、系统、快捷键、API、多结局规则）在 [game/README.md](game/README.md)。

## 资料怎么读

第一次接触这个项目，建议按这条线走：

1. `资料/01_剧情文本/原文剧本.txt` —— **故事从哪来**（第一人称视觉小说原文，全项目文本源头）
2. `资料/02_设定与设计/人物设定与关系总览.md` —— **人物怎么定**（人物圣经 v1.0）
3. `资料/02_设定与设计/架构设计V1.md` —— **引擎怎么搭**（五层架构总纲）
4. `资料/01_剧情文本/游戏流程架构与流程通路.html` —— **代码怎么跑**（总流程图与流程通解）
5. `game/` —— **代码本体**

`资料/README.md` 里有一份按模块分组的完整索引。

## 两个容易踩的坑

- **游戏状态活在服务进程里**，不在浏览器。重启服务会重置进行中的进度（存档文件不受影响）；开两个标签页会争用同一局。
- **`资料/` 里的生图源文件是开发脚本的输入**，不是可直接删除的中间产物；`game/tools/paths.py` 记录了这个路径
  （也可用环境变量 `GAL_ART_SRC` 指向别处）。
