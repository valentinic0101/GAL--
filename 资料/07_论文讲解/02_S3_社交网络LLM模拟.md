## 二、论文本身

### 2.1 要解决的问题

把 LLM agent 模拟从 Smallville 的 25 人小镇推到**真实社交网络尺度**：能否在真实网络结构上模拟信息传播、情绪传播和态度转变，并且和真实数据对得上。

### 2.2 方法：四组件系统

1. **User Characterization（用户画像）**：真实数据缺属性时由 LLM 补全——用真实 Twitter 数据微调 ChatGLM 预测性别（准确率 71.0%）、年龄（MSE 128.0），1000+ 种职业归并为 10 大类。
2. **Memory Pool（记忆池）**：每条消息对 agent 的影响 = f(时间衰减, 内容相关性, 信源真实性)。
3. **Behavior Generation（行为生成）**：LLM 生成转发/评论/发帖等行为。
4. **Environment（环境）**：加载真实社交网络拓扑 + 信息流/推荐更新。

统一模拟**情绪、态度、互动**三层，配合 MapReduce 范式的并行引擎支撑万级 agent。

### 2.3 关键结果

- 信息传播、情绪传播、态度转变三条线都能复现真实数据中的**S 型传播饱和曲线**。
- 情绪传播 zero-shot（不用训练数据）即超过需要训练数据的传统基线。

## 三、评价所用的技术

评测走"**与真实数据对齐**"路线，这是 LLM-ABM 的经典评测范式：

- **信息传播**：用 Mean Squared Error of Diffusion（MSED）衡量模拟转发规模与真实曲线的偏差——性别歧视话题 MSED **0.043**、核能话题 **0.087**，优于线性阈值（LT）/独立级联（IC）等传统传播模型的 0.051–0.398。
- **情绪传播**：MSED 0.053、相关系数 **0.731**，zero-shot 即超过 Voter、DeGroot、FNN、SINN、NDCN 等需训练数据的基线。
- **态度**：初始态度预测准确率 **74.3%**、态度转变预测 **83.9%**。

## 四、对 GAL 项目的启发

1. **传播影响函数**：Message Influence = f(时间衰减, 内容相关性, 信源真实性) 可以直接改造成"传闻条目强度"——亲戚对"雪衣少女"传闻的兴趣随时间衰减、与各自执念（遗产/神社/老屋）的相关性挂钩。
2. **先补画像再模拟**：本项目人物圣经本身就是完整画像，不需要 S³ 的补全步骤——但它的"职业归并为大类"思路提示：**配角的性格过滤器可以做成粗粒度模板**，不必人人一套 prompt。
3. **评测范式**：给传播引擎做回归测试时，别只看"传闻传到了谁"，还要看**传播曲线形状**（是否符合预期的时间/人数分布）。
