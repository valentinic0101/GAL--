# 开发文档 C2：角色反思与信念沉淀（Reflection）

- **总报告排名**：第 6 位 ｜ 相关性 9 · 适用性 8 · 补充价值 9 ｜ 总分 26
- **论文依据**：《论文讲解/01_Generative_Agents》——reflection：新近记忆重要性累积超阈值（原文 150）时触发，由"最近 100 条记忆"生成高层洞察写回记忆流，形成"事件→信念"的树状抽象；《论文讲解/07_Project Sid》——去掉 Social Awareness 模块则社会分化消失：**没有对他人状态的信念，群体行为就不涌现**；《论文讲解/08_AgentSociety》——情绪/认知/社会关系分层驱动。**直接依据**：《架构设计V1.md》坑 3「定期反思生成人物洞察（如亲戚们沉淀出『那孩子回来必定是为了老屋』这类信念，反过来影响后续行为）」——设计写了，实现没有。
- **批次**：第 2 批（紧随 C1）｜ **预估**：1 天 ｜ **依赖**：C1（反思的原料是记忆流）

## 一、目标（一句话）

当重要经历累积到阈值，角色**暂停、反思、生成洞察**写回记忆流：深雪沉淀出"小修在逃避东京而非向往雪国"，亲戚群像沉淀出"那孩子回来必定是为了老屋"——信念反过来影响后续台词与传播。

## 二、现状与差距

- 角色对"局势"完全没有高层认知：P3 雪仗大胜后，深雪对修二的"认知"仍是零条 episode（C1 解决"记事"）；即使 C1 上线，记忆也只是**流水账**——"他说喜欢雪"+"他骂我丑八怪"+"他答应明年回来"三条并列，没有"这个孩子嘴硬心软"这样的**抽象**；
- 亲戚没有执念：架构 V1 §2.2 的核心示例（亲戚会议推诿 → 数日后传闻扭曲 → 鸟羽老人上门）中，"推诿"与"传闻"之间缺了一环——**亲戚们先要形成'遗产怕要出问题'的信念，才会按此过滤和放大传闻**；
- 规则引擎的亲戚台词是静态池，与剧情进展无关。

## 三、详细修改方案

### 3.1 触发器（agents/memory.py 内新增 `maybe_reflect`）

```python
class World:
    def __init__(self):
        ...
        self.reflect_points = {c: 0.0 for c in CHARACTERS}   # 反思能量槽

# 写入钩子里累积（C1 的 4 个钩子尾部）：
w.reflect_points[char] += m.importance    # 只累积 importance，新近的才算数

# 触发检查（engine.end_scene() 调用一次，每场景至多一次/角色）：
REFLECT_THRESHOLD = 40     # 标定：P1~P3 深雪经历 importance 总和 ≈ 25+18+22，
                           # 场景末约 65——即 P3 后必然触发首次反思（对应原文节奏）
if w.reflect_points[char] >= REFLECT_THRESHOLD:
    w.reflect_points[char] = 0
    insights = reflect(char, w)
```

（对照论文：Smallville 用 importance 和 >150、约每天 2~3 次；本作场景数少、单场景信息密度高，阈值按"每 2~3 个场景反思一次"标定，写入配置常量。）

### 3.2 反思生成（agents/memory.py `reflect(char, w)`）

```python
def reflect(char, world):
    recent = world.memory[char].latest(n=30)          # 最近 30 条
    important = [m for m in recent if m.importance >= 5]
    if LLM.available:
        prompt = INSIGHT_PROMPT.format(               # persona + 记忆列表
            persona=persona_card(char),
            memories='\n'.join('- ' + m.content for m in important),
            rules='只输出一行 JSON {"insights": ["洞察1", "洞察2"]}，'
                  '每条洞察是一句关于他人或局势的高层判断，'
                  '不要复述事件本身，不要说出你人设中不可能知道的信息。')
        out = LLM.chat(prompt, ..., max_tokens=200)
        insights = json.loads(...)['insights'][:2]
    else:
        insights = offline_insights(char, world)      # 模板兜底，见 3.3
    for s in insights:
        world.memory[char].add(MemoryEntry(
            content=s, kind='insight', day=world.day,
            importance=9, source='reflection',
            keywords=extract_keywords(s)))
    world.emit('reflection', {'char': char, 'insights': insights})
```

### 3.3 离线模板兜底 `offline_insights(char, world)`（按 flag 组合预写）

| 角色 | 触发 flags | 洞察 |
|---|---|---|
| miyuki | likes_snow ∧ snowball_fight | 「小修嘴上凶得很，其实一点都不讨厌这里——也不讨厌我。」 |
| miyuki | height_marked ∧ left_town | 「约定这种东西，对人类的孩子来说，是要用整整一年来遵守的。」 |
| relative_man/woman | comforted ∧ met_miyuki | 「那孩子回来，怕不只是过寒假——老屋的事，没那么简单。」 |
| toba | gossip 到达 ∧ met_miyuki | 「老屋那边的事，瞒不了多久了。」

### 3.4 洞察的消费（让它"反过来影响行为"）

1. **进 prompt**：`assemble_prompt` 增加一段【你对局势的看法】（kind=insight 的记忆天然会经 C1 检索进入——insight importance=9 恒被检索到，无需额外改动；此条确认即可）；
2. **驱动台词**：`rule_engine.miyuki_respond` 的 smalltalk 池检查记忆流是否有 insight，有则 30% 概率优先输出含该洞察语义的变体（离线池各配 1 句）；
3. **驱动传播**（联动 C8）：亲戚持有"遗产/老屋"类 insight 时，其 `PERSONALITY_FILTERS` 传播概率 +0.15、扭曲概率 +0.2——**信念放大传播**，这正是架构 V1 示例的机制化。

## 四、验收标准

1. 单测 `test_reflection.py`：
   - 构造重要记忆累积 ≥ 阈值 → 断言触发且产出 kind=insight 条目（importance=9）；
   - 离线模板：P3 结束后深雪必产出"嘴硬心软"类洞察（flag 组合命中）；
   - 反思能量槽序列化回环。
2. 实机（LLM 开）：P3 幕间问深雪「你觉得我是个怎么样的孩子」——应答语义与"嘴硬心软"洞察吻合（judge 轨或人工 5/10 抽检 ≥7 命中）。
3. 亲戚侧：P3 后 wait 2 天 → 传闻扩散速度（C8 前先断言知识条目数）快于无反思基线。
4. 全量回归三脚本绿。

## 五、风险与回滚

- **洞察越界泄谜**：深雪的洞察可能被 LLM 写成"因为我是雪女所以…"——INSIGHT_PROMPT 里明确"不要说出你人设中不可能知道的信息"+ 产出后过一遍 `guardrails.check_miyuki`（复用 C3），违规洞察丢弃；
- **触发过频**：阈值 + 每场景每角色至多一次 + 能量槽清零，成本可控（LLM 路径每场景至多 1 次额外调用）；
- **回滚**：`maybe_reflect` 是独立调用点，置 `settings.REFLECT_ON=False` 即完全关闭。
