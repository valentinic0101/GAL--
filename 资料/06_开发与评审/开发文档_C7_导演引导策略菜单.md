# 开发文档 C7：导演层 diegetic 引导策略菜单（剧情引力 2.0）

- **总报告排名**：第 7 位 ｜ 相关性 9 · 适用性 8 · 补充价值 8.5 ｜ 总分 25.5
- **论文依据**：《论文讲解/24_SENNA》——用户实验实证：diegetic（游戏世界内自洽）引导——提供信息、让世界产生后果、借 NPC 影响、调整时机——在不牺牲自主感与沉浸感的前提下维持叙事连贯；hard denial 反响最差；"约束如何被传达与执行，和约束本身同等重要"；《论文讲解/23_互动戏剧》——plot-based reflection：每 N 步对剧本做**有界修订**（最多改 1 个未完成 plot / 插入 1 个新 plot），玩家行为被吸收但骨架不散；《论文讲解/15_DOC》——大纲控制：自由过程 + 既定骨架。
- **批次**：第 4 批 ｜ **预估**：1 天 ｜ **依赖**：无硬依赖；C1/C2 上线后 NPC 影响型策略更有料

## 一、目标（一句话）

玩家滞留/跑题时，导演层不再只会递压力值换一句固定提示（"雪还在下……"），而是从**四种 diegetic 策略**中选择一种，把下一个剧情事件"推到玩家面前"——自由度不动，引力变智能。

## 二、现状与差距（代码级）

- 引导现状 = `engine.interlude_act()` 每步 +6 `season_pressure`、`wait` 再 +10；`director.should_advance()` 压力 ≥70 时 `_after_interlude` 挂出「▶ 推进剧情」按钮 + `_interlude_hint` 一句提示；
- `_interlude_hint`（engine.py:327-343）按下一场景硬编码 4 种文案，且是**元叙述**口吻（"你说的每一句话，都在决定故事的去向"）——玩家滞留 10 步看到的还是同一句"雪还在下。你可以四处走走……"（:343）。这正是 SENNA 判定为最差体验的 **hard denial 式引导**（游戏在说"该推进了"，而非世界自己在动）；
- 引导不看玩家行为：在鸟羽老人家连聊 5 句 vs 在站台干等 5 步 vs 反复打听谜团，得到的引导完全相同。

## 三、详细修改方案

### 3.1 行为特征采集（engine.py 幕间行动处埋点，聚合进 director）

```python
# director.py 新增
class Director:
    def __init__(self, world):
        ...
        self.idle_steps = 0          # 距上次剧情推进的幕间行动数
        self.location_stay = {}      # location -> 连续行动次数
        self.mystery_probes = 0      # 命中 ask_mystery/ask_identity 意图的交谈数
```

`engine.interlude_act` 各分支末尾调用 `self.director.on_interlude(action, payload)`（新增方法）：移动/交谈/等待分别更新三个计数；`_agentRespond` 意图命中谜团类时 `mystery_probes += 1`。

### 3.2 策略选择器（director/guide.py 新模块）

```python
def choose_strategy(d: Director) -> dict:
    """返回 {'strategy': str, 'payload': dict}。顺序即优先级（SENNA 六式的 diegetic 子集）。"""
    w = d.world
    nxt = d.route()                       # 下一个可进入场景（ATTRACTORS 已判定）
    if nxt is None or d.idle_steps < 3:
        return {'strategy': 'none', 'payload': {}}          # 未滞留，不引导
    if d.mystery_probes >= 2:
        return {'strategy': 'npc_redirect', 'payload': {'nxt': nxt}}   # 引开谜团话头
    if d.location_stay.get(w.location, 0) >= 4 and movable(w.location):
        return {'strategy': 'event_comes', 'payload': {'nxt': nxt}}    # 事件上门
    if d.idle_steps >= 6:
        return {'strategy': 'world_consequence', 'payload': {'nxt': nxt}}
    return {'strategy': 'info_hook', 'payload': {'nxt': nxt}}          # 默认：信息钩子
```

### 3.3 四种策略的执行（engine.py `_after_interlude` 改造）

| 策略 | diegetic 原理 | 实现 |
|---|---|---|
| **info_hook 信息型** | 旁白递进环境信息，把下一场景的钩子写进世界 | `note = rule_engine.hook(nxt, w)`：新函数按场景返回钩子文案（P4→"参道方向，隐约有木鼓声试音"；P5→"炉火该添炭了，姐姐说今晚要量身高"；P11→"归期就在明天"），替代 :343 的固定文案 |
| **npc_redirect NPC 影响型** | NPC 主动出现把话头带走 | 深雪（若在世界逻辑上可达）直接登台说一句主动台词（复用 rule_engine 行为模式库"提议类"），同时 `mystery_probes = 0`；谜团话题被"我们去堆雪人吧"自然替代 |
| **event_comes 时机调整型** | 不要求玩家去，事件来找玩家 | 对 ATTRACTORS 中含地点条件的场景（P5 要求 `oldhouse_in`、P9 同）放宽执行：满足其余条件且滞留时，在**当前地点**给出场景入口（`scene_offer` 直接挂出，附一句深雪"那我们回老屋吧"式的过场旁白） |
| **world_consequence 世界后果型** | 世界记住玩家的行为并回应 | 若存在当日 gossip 新条目，note 改为传闻内容（"镇上的人在议论……"）；否则 season_pressure 额外 +10（时间不等人，冬祭倒计时收紧）——世界在"催"，但用世界的方式 |

**降级链**：`idle_steps >= 10` 仍不推进 → 允许一次半显式引导（hint 文案但保持叙事措辞："再待下去，冬天就要过去了"）——SENNA 承认 hard denial 存在但必须最后用、最少用。

### 3.4 P11+ 分支层的配合（有界修订思想，最小化实现）

P12B 决策前若玩家 `mystery_probes` 持续偏高（执念行为溢出但轴未到 35），在 P12B 的 branch_text 加一条 `axis:obsession>=25` 的过渡文案（"你在意起群山的方向"）——不改轴值、不改结局条件，只给"落空"一个铺垫。此项为 script.py 一处 branch_text 追加，防止引导系统与分支系统"打架"。

## 四、验收标准

1. 单测 `test_guide.py`：构造 4 种滞留状态（谜团连问/同地久留/纯等待/轻度滞留），断言各命中预期策略；`idle_steps<3` 恒 none；
2. 实机脚本（离线可跑）：从 P3 起连续 `wait`×8，断言收到 ≥3 种不同策略的 note（不再重复同一句）；谜团连问 2 次后下一句 NPC 台词为深雪主动提议类；
3. SENNA 式小样本人评（可选，2 人 × 5 分钟）：滞留体验"被世界引导"主观感受优于旧版固定文案；
4. 全量回归三脚本绿；P1→结局全通路耗时（离线步数）无回归。

## 五、风险与回滚

- **策略互相打架**：选择器是严格 if 链 + 幂等计数，单测穷举保证；策略执行只改 note/登台/scene_offer，不碰 SUCCESSORS 与门控——分支收束性不受影响（test_branching 兜底）；
- **演出依赖**：npc_redirect 的中途登台与 E-3（BUG-3 立绘按拍入场）共用机制，故排第 4 批；
- **回滚**：`settings.GUIDE_V2=False` 一键回落旧 `_interlude_hint` 逻辑（保留原函数不删）。
