# 资料 —— 项目资料索引

本目录收的是**做这个游戏时用过和产出的东西**：剧本原稿、设定、生图源文件、论文笔记、评审记录、UI 改版方案。
**运行游戏不需要这里的任何文件**（唯一例外见文末「与 game/ 的关系」）。

按「这东西拿来干什么」分成七组，不按文件类型分——所以剧本原文和分支树图放在一起，生图提示词和生图源文件放在一起。

```
资料/
├── 01_剧情文本/       故事本身：原文剧本、分支树、流程通路图
├── 02_设定与设计/     人物圣经、多结局设计、舞台规范、架构总纲、研究综述
├── 03_美术/          生图提示词、AI 生图源文件、实机测试截图
├── 04_音频视频/       BGM 需求文档、CG 动态视频提示词
├── 05_UI改版方案/     三套候选设计 + 示例图 + 落地验证截图 + 改版前原文件备份
├── 06_开发与评审/     总报告、C1~C8 开发文档、过程文档、抠图修复对比
└── 07_论文讲解/       31 篇论文逐篇讲解（研究材料库）
```

选定 A 并落地到 `game/`。

| 路径 | 说明 |
|---|---|
| `README.md` | 11 点诊断（带实测数据）、三套设计对比、选型依据、落地结果与复现方式、检索来源。 |
| `A_雪月花/` `B_灯条/` `C_留白/` | 各自的 `mockup.html`（8 屏，按 URL hash 切换）与 `示例图/`。 |
| `落地验证截图/` | 真实游戏里的改版前 / 改版后对照。 |
| `00_改版前原文件备份/` | 改版前的 `index.html` / `main.js` / `style.css`，即当时的 `*.bak`。保留它们是为了在需要时能对照或回退。 |

## 07_论文讲解

31 篇论文逐篇讲解（`01`~`31` + `README.md`），涵盖生成式智能体、社会模拟、互动戏剧、
叙事生成、记忆机制、世界模型等方向。`game/server/` 里不少设计（导演引导、记忆检索、谜团攻击集）
直接标注了对应篇目，代码里写作《资料/07_论文讲解/xx_…》。

## 与 game/ 的关系

只有一条**单向**依赖：`game/tools/integrate_art.py` 与 `game/tools/cutout_sprites.py` 会读
`资料/03_美术/AI生图源文件/`。这条路径集中记录在 `game/tools/paths.py`，
可用环境变量覆盖（`GAL_ART_SRC=/path/to/源文件`），搬动本目录时改那一处即可。

游戏**运行期**（`server/` + `web/` + `assets/`）不读本目录的任何文件。
