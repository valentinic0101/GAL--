## 一、原作结局判定（重读原文剧本的结论）

原文剧本是**纯散文式线性叙事，没有任何选项与分支，结局固定且是开放式的**：

1. 全文只有一条故事线：雪山序章 → 初遇 → 清雪 → 雪仗 → 冬祭 → 刻身高 → 送站拉勾 → （三年后）重逢 → 同居日常 → 再量身高 → 齐刘海离别。
2. 结尾停在深雪的提问 **「小修，觉得现在幸福吗……？」**——原文用四遍"然而，实际上……"表示修二答不出口，最后以「田间小路上并排的两行黑色足迹／少女凝视群山」的画面收束。**问题没有被回答，故事没有结局只有余韵。**
3. 两段**游戏未采用**的素材，正好是新分支的种子：
   - **第二次雪原幻视**（送站与三年后之间）：雪原上伫立着"面容＝自称是姐姐的那个女孩"的白衣身影——入山线的铺垫；
   - **返乡决定住进老屋**（P7 到站前明确交代"我已决定在返乡时，住在老屋里了"）——留守线的依据。

## 二、结局总设计：三轴 · 四结局

### 2.1 三轴（玩家说话的能动性量化）

主角修二的内心去向被量化为三根轴（0~100，存于 `world.axes`）：

| 轴 | 含义 | 升高途径 |
|---|---|---|
| **羁绊 bond** | 对深雪／约定的依恋 | 温暖选项、主动谈她、约定类话题 |
| **执念 obsession** | 对父母／群山／谜团的执念 | 谈父母之死、山、雪女、追问谜团 |
| **现世 worldly** | 对东京／学业／现实生活的锚 | 谈学校、升学、东京、朋友、将来 |

**打分机制（模型打分进分叉）**：自由输入（场景 `free` 节拍 + 幕间交谈）每句由打分器判定三轴增量（LLM 严格 JSON 输出，离线/失败回落关键词规则），打分后立即插一句**修二的内心独白旁白**作为反馈——玩家能看见"这句话把我推向了哪里"。正典选项也各自携带轴增量。

初始值 bond=20 / obsession=15 / worldly=15；阈值 **羁绊≥50、执念≥35** 为关键门槛。

### 2.2 分叉点

- **D0 · 一年后的岔路（新场景 P11，P10 之后）**：三选一，**全部可见、点击时判定阈值**，不足者叙事化拒绝并回落归省——
  1. 「先去群山——去父亲和母亲所在的地方」（执念≥35，不足则剧情化落空）→ P12M 雪径 → P0；
  2. 「回到雪国——回到姐姐身边」（永远可用）→ P12B；
  3. 「今年，就留在东京吧」（现世≥35，不足则剧情化落空）→ 直接 E_FAR。
- **D1 · 幸福之问（新场景 P12B，田间小路）**：原文没答的那句话由玩家亲口回答（自由输入打分），然后三选一——
  1. 「那就，留在这里」（羁绊≥50）→ E_STAY；
  2. 「春天，樱花开的时候，我再来见你」（羁绊≥50 且 执念<35）→ E_SPRING；
  3. 「（话没有说完整）」（永远可见，兜底）→ E_FAR。
- **门控失败不产生死路**：选中被门控拦截的路线时，场景内以剧情方式"落空"（深雪轻轻推开这个提议／修二自己语塞），收束进 E_FAR 的对应变体——**每条线必达某个结局**。

### 2.3 四个结局

| 结局 ID | 标题 | 线 | 情绪 | 到达条件 |
|---|---|---|---|---|
| `END_SNOW` | **白之彼方** | 入山线 | 悲壮·成谜 | P11 选「先去群山」→ P12M 雪径（原文第二次雪原幻视意象）→ P0（现场景保留为终幕） |
| `END_STAY` | **炉火与春讯** | 留守线 | 温暖·隐忧 | 羁绊≥50，P12B 答"幸福"后选「留在这里」；结尾深雪轻问「春天来了的话，小修还会在吗？」 |
| `END_SPRING` | **等到花开** | 真结局 | 释然·圆满 | 羁绊≥50 且 执念<35，选「春天再来」；春假返乡，雪融樱开，她在樱花树下「雪化了，我也在哦」；**修复死 flag：`accepted_sister` 在此置 True（齐刘海仪式完成）** |
| `END_FAR` | **两行足迹** | 原作向 | 怅然·余韵 | 默认兜底（留东京／说不出话／门控落空）；用原文结尾意象收束（两行足迹·凝视群山·停摆的钟），并按落空原因给 3 种变体旁白 |

**谜团锁红线**：四个结局均不回答"她是什么／父母是否在山中"——只给氛围与事实（"她在"），不给解释。E_SPRING 中深雪对"为何春天也在"仅以「因为约好了」带过（STAGE_NOTES 硬约束）。

## 三、场景分支图（实现后的真实拓扑）

```
P1 → P2 → P3 → P4 → P5 → P6 → P7 → P8 → P9 → P10   （主干：9 处选项喂轴，变体台词后收束回主干）
P10 → P11「一年后的岔路」
        ├─ 选「入山」(执念≥35) ──→ P12M「雪径」──→ P0「白之彼方」═══ END_SNOW
        ├─ 选「归去」──────────→ P12B「幸福之问」
        │        ├─ 选「留下」(羁绊≥50) ──→ E_STAY ═══ END_STAY
        │        ├─ 选「春天再见」(羁绊≥50 ∧ 执念<35) → E_SPRING ═══ END_SPRING
        │        └─ 兜底/落空 ──────────→ E_FAR ═══ END_FAR
        └─ 选「留京」(现世≥35) ──→ E_TOKYO「东来的雪」═══ END_FAR（与 E_FAR 同结局 ID）

> 实现说明：留京线拆为独立场景 E_TOKYO（东京视角独白），与 E_FAR 共用结局 ID `END_FAR`。
> 决策节拍的自由输入若命中选项意图则视同选择；未命中只做对演、不跳过决策——分叉必须由玩家明确按下。
```

- 导演层用 **SUCCESSORS 后继表**替代线性 PHASE_ORDER：每个场景给出按序求值的候选后继 + 条件，**任何状态恰好一个可进入的后继或到达吸收态结局**（`route()` 为纯函数，可穷举测试）。
- 结局是**吸收态**：进入 E_*／P0 后置 `flags['ending']`，导演不再推进（可留在幕间漫游回忆）。

## 五、测试方案（任务⑤）

1. **静态**：每个场景后继非空或为吸收态；每个选项节拍至少一个无门控选项；`route()` 在全部决策 flag 组合 × 轴边界值下必有归宿。
2. **动态**：四条路线各实机通关（纯离线规则回落，确定性关键词泵轴），断言各自到达正确结局；`END_SPRING` 额外断言 `accepted_sister is True`。
3. **无悬挂**：结局后 `should_advance()` 恒 None、advance/act 连续调用不报错；打分器离线可用；存读档后轴值保留。
