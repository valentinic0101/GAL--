## 二、发现的问题（按优先级，交实现会话修复）

### BUG-1（P0 · CG 完全不显示，所有玩家必现）
`web/index.html:92`：`<div id="cg-overlay">` 被嵌在 `<div id="interlude-panel">` 内部。后果双重：
1. `hideAllPanels()` 在 CG 帧把 interlude-panel 隐藏（display:none），CG 随之消失；
2. 面板的 `transform: translateX(-50%)` 使其成为 fixed 子元素的包含块，即使显示，CG 也被压进面板小盒里。
**实测**：cg 帧下 overlay opacity=0 / 尺寸 0。**修复已在测试中模拟验证**：把该 div 移出为 `#game-screen` 直接子元素后，cg02 立即完美呈现（见 12_P2_CG02_模拟修复后.png）。一行 DOM 移动即可。

### BUG-2（P1 · 结局吸收态的背景回落错位）
`engine.enter_scene()` 只应用场景头 `bg`（_bg_override），不应用 `location/time`；而 `scene_end` 又清除 _bg_override → 结局后的幕间帧回落到 **旧地点** 的默认背景：
- E_SPRING 结局卡显示**冬季积雪庭院**图（bg_courtyard.png），与「樱花开」文案直接矛盾（截图 06）；
- E_TOKYO 结局卡显示**雪国车站**，应为东京街景（截图 08）；
- P12B/P6 等场景 HUD 地点滞后（P12B 显示「上山站」应为「田间小路」；P6 显示「老屋·客厅」）。
**修复建议**：`enter_scene` 同步 `w.location/w.time_slot = sc['location']/sc['time']`；且进入吸收态结局时保留最后场景的 _bg_override（或在 ENDINGS 场景的 scene_end 不清 override）。

### BUG-3（P2 · P7 重逢揭晓演出矛盾）
P7 第一拍旁白【三年后】「令人怀恋的那张面庞，理所当然地没有出现」，但静态 SCENE_CAST 使深雪从第一拍就站在站台上（截图 21）。**修复建议**：支持立绘按拍入场——P7 的 SCENE_CAST 初始为 ['shuuji']，在深雪首句台词拍（「咦――」）入场；可在 beat 上加可选 `cast` 字段，engine.step 时若 beat 带 cast 则更新 self.present。

## 五、附录 · 第四轮：自由输入反馈与快捷回答改造（2026-09-16 07:40，监督会话执行）

### 用户反馈的两个问题与根源

| 问题 | 根源 | 性质 |
|---|---|---|
| ① 自由输入"根本没有得到回复"，剧情照旧 | `main.js playFrames()` **只渲染最后一帧**：引擎返回的 `[你的话 → 她的回应 → 下一拍]` 帧序列中，回应帧被下一拍直接覆盖。实测幕间交谈有高质量 LLM 回应（src=llm）但玩家永远看不到 | 前端显示层 bug |
| ② 快捷回答「聊起雪/试探身世/沉默」全场景通用 | 三个按钮**硬编码在 index.html**，与场景无关 | 静态 UI 缺陷 |

### 修复内容

1. **帧队列播放器**（`main.js`）：一次响应的多帧改为逐帧展示、点击推进；遇选项/输入/幕间等交互帧即停。你的话、她的回应各自独占一屏。
2. **服务端兜底**（`engine.submit_input`）：free 节拍/普通选择节拍打字后，回应之后不再立即拼接下一拍——下一次 advance 才继续剧情；决策拍打字未命中选项时，回应后补一句「（心意已经传达到了。但脚下的路，还是要自己选的。）」再重显选项。
3. **动态 chips**（`index.html` + `main.js` + `script.py` + `engine.py`）：删除写死按钮；free 节拍新增 `chips` 字段逐场景定制（P1「问她是谁/放开我啦」、P8「打扑克/堆雪人/晚安」、P12B「很幸福/望群山」、E_STAY「晚安/春天」）；幕间交谈新增 `INTERLUDE_CHIPS` 逐场景话题建议（仅当有人在身边时下发；且这些话题会喂三轴——话题即去向）。
4. **提示修正**：P10 结束后的幕间提示不再说「多和她说说话吧」（此时深雪不在场，说了也无人回应）。
5. 接入管线 `patch_script` 对最后一个场景切 bg 时越界崩溃的边界修复。

### 回归与实测

- 一致性 32/32、分支收束 ALL PASSED（门控落空测试已适配"回应独占一屏"的新节奏）。
- 实机验证截图：35（P1 专属 chips）、36（玩家的话独占一屏）、37（深雪针对性回应独占一屏——问名字→她答名字）。
- 静态资源版本 bump 至 ?v=19。

### 已知残留

- LLM 回应偶发 10s+ 延迟（右下角有「等待深雪回应」指示，但提示较小）——建议后续把等待指示放大或加草稿气泡；超时回落规则引擎的回复较模板化。
- 自由输入对剧情的作用方式是"三轴累积 + 分支解锁 + 回应演出"，单场景内节拍序列仍按剧本走——这是设计选择，如需"对话改变当前场景演出"属下一阶段的大改造。
