⑤ LLM 配置（game/llm.json）

{
  "apiKey":   "sk-...",
  "baseUrl":  "https://api.deepseek.com",
  "model":    "deepseek-flash",
  "extraBody": { "thinking": {"type": "disabled"} },   ← 关思考模式（重要：开启时 token 全被推理吃掉，正文为空且延迟暴涨）
  "timeout":  25
}
调用链：玩家输入 → 护栏前校验 → 现场拼装（人设卡+记忆+场景+知识边界+阶段约束）→ DeepSeek → 护栏校验（称谓/语气词/禁忌词/谜团锁）→ 违规重试 ≤2 次 → 仍失败回落规则引擎。台词帧 src 字段标明 llm / rules。测试离线开关：POST /api/mode {"llm":false}。
