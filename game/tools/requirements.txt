# 美术工具依赖（tools/ 下的脚本用）
#
# 这个环境只服务美术流水线，游戏运行不需要它：
#   游戏本体依赖只有 fastapi / uvicorn / pillow（装在系统 Python，见 game/README.md）
#
# 重建方式：
#   cd game/tools
#   python3 -m venv .venv
#   .venv/bin/python -m pip install -r requirements.txt
#
# 关键包说明：
#   rembg          AI 抠图（isnet-anime 模型），cutout_sprites.py 的主算法
#   onnxruntime     rembg 的推理后端（体积最大，约 60MB）
#   opencv-python-headless / scipy / scikit-image / PyMatting / numba / llvmlite
#                  rembg 与其图像处理链拖来的间接依赖（合计约 350MB）
#   pillow          生成背景/立绘/UI 用（gen_backgrounds.py / gen_sprites.py / _tools.py）
#   numpy           音频合成（gen_music.py）与抠图的数组运算
#
# 注意：不装 rembg 时 cutout_sprites.py 会自动退回旧的「边框取色 + 洪泛填充」算法，
#       能跑但立绘边缘质量较差（脚本会打印警告）。只想跑背景/立绘生成的话，
#       装 pillow + numpy 就够了（约 33MB，而不是 495MB）。
