## 二、论文本身

### 2.1 框架

提出统一的 **"construction–application–evaluation"（构建–应用–评测）**组织框架：

- **构建**：agent 四大模块——
  - **Profile（画像）**：人设从哪来（手写 prompt / 数据集 / LLM 自生成）；
  - **Memory（记忆）**：短期/长期、检索、反思；
  - **Planning（规划）**：任务分解、反思改进；
  - **Action（行动）**：工具调用、具身行动。
- **应用**：社会科学（含社会模拟）、自然科学、工程三大领域。
- **评测**：方法论分类。

### 2.2 历史地位

Smallville 的记忆流/规划架构，正是这篇综述"memory + planning"框架的最著名实现。对 2023 年而言它是领域地图；对今天而言它是**术语词典**——读后续论文时反复会撞见它定义的概念。

## 三、评价所用的技术（综述对评测的分类）

把 agent 评测归纳为两条线：

- **主观评测**：人工评估 + LLM-as-a-Judge 式评判；
- **客观评测**：精度类指标（准确率、ROUGE 等）与真实世界任务协议对齐。

这是"如何评 agent"的早期分类学——后来各论文的评测基本是这两个轴的组合。

## 四、对 GAL 项目的启发

1. **词汇表**：写技术文档时用它的术语（profile=人设卡、memory=记忆库、planning=日程/导演、action=台词+动作输出），与学术社区沟通零成本。
2. **"画像从哪来"的三分法**：手写（本项目人物圣经）/ 数据驱动（千人分身式访谈）/ LLM 自生成——本项目属于最强的一档，这与千人分身"访谈 grounding 最准"的结论互洽。
3. 过时部分：未覆盖其后爆发的具身/多智能体社会模拟与游戏 agent 浪潮，深度上是模块描述多于机制分析——需要搭配本合集其他文档补新。
