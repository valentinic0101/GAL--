## 🎯 与 GAL 项目的相关度：9.5 / 10

## 二、论文本身

### 2.1 要解决的问题

LLM 单次调用会"说话"，但能不能让 LLM 长期"生活"？论文要证明：把 LLM 当作人来构建 agent，在一个持久世界里会产生**可信的、涌现的社会行为**，而不是每一步都随机漂移的木偶。

### 2.2 方法：单 agent 内部的认知管线

25 个 agent 生活在《模拟人生》风格像素小镇 Smallville，每个 agent 有人设（名字、职业、性格、记忆起点、社交关系），运行 2 个游戏日。核心是四段管线：

1. **Memory Stream（记忆流）**：感知到的一切（看到谁、听到什么、自己做了什么）都变成自然语言记录 + 时间戳，追加进不断增长的列表。
2. **检索（Retrieval）**：三因子加权打分决定"现在该想起什么"——
   - *Recency*：距上次被检索的时间按指数衰减，衰减因子 **0.995/游戏小时**；
   - *Importance*：记忆生成时让 LLM 打 1–10 的 "poignancy" 分（"吃早餐"=1，"失恋"=9）；
   - *Relevance*：当前情境与记忆 embedding 的余弦相似度。
3. **Reflection（反思）**：当新近事件的重要性分数之和超过阈值 **150** 时触发（约每天 2–3 次）：LLM 先从最近 100 条记忆生成高层问题，再提炼出洞察（"Klaus 在研究歧视" → "Klaus 是专注的社会学者"），洞察写回记忆流，形成树状抽象——这是"从事件记忆到信念"的关键一步。
4. **Planning → React**：先以"天"为单位生成日程，递归分解到小时、再到 5–15 分钟的行为块；每次观察后判断要不要响应（继续做事/找人搭话），对话历史写回记忆流——所以八卦会真实地传开。

### 2.3 关键结果：两个标志性涌现现象

- **情人节派对**：酒馆老板 Isabella 自发决定办派对 → 逐一邀请 → 布置场地 → 消息口口相传。派对信息知晓率从 **4% 涨到 52%**（1→13 人），12 名被邀者 5 人到场，谁没来都符合社交逻辑。
- **市长竞选八卦**：候选人 Sam 拉票的信息通过 Klaus 中转给 John——经典信息级联。竞选信息知晓率 4%→32%。
- 社交网络密度从 0.167 增长到 **0.74**；453 条记忆陈述中仅 **1.3%**（6 条）是幻觉。
- 成本：gpt-3.5 跑 25 agent × 2 游戏日 ≈ **1000+ 美元**——后来所有工作都要面对的规模化瓶颈。

## 三、评价所用的技术

这是本文对评测方法学最有参考价值的部分——**"采访式"人评 believability**：

- **被试内设计，100 名评估者**：同一评估者观看同一 agent 的多份"采访录像"，判断哪份更像真人。
- **5 个条件对比**：① 完整架构；② 去掉 reflection；③ 去掉 reflection+planning；④ 三件套全去掉；⑤ **真人 crowdworker 代写**（人类基线，且等于此前工作的水平）。
- **访谈提纲**：25 个问题，覆盖自我认知/记忆/计划/反应/反思 5 类各 5 题——用提问把 agent 的"内心状态"逼出来再打分。
- **统计方法**：评估者做全排序，换算成 **TrueSkill** 评分：完整架构 **μ=29.89** > 无反思 26.88 > 无反思+规划 25.64 > crowdworker 22.95 > 全消融 21.21。完整架构对全消融效应量 Cohen's d = **8.16**，Kruskal-Wallis 检验显著。
- **消融结论**：去掉 planning 掉分最狠，其次 reflection；只留记忆流不反思也不行——三件套缺一不可。

**可借鉴的评测范式**：给 agent 出"内心状态问卷"、让真人盲选"哪份更像人"、用消融实验证明每个模块都有用——这三招本项目阶段 0 的"自动评测看正典语料吻合度"可以直接升级。

## 四、对 GAL 项目的启发

1. **记忆检索三因子照抄可用**：称谓/语气词检索时加 recency 衰减与 importance 分，避免"回忆起吃早餐却忘了被推诿遗产"。
2. **Reflection 阈值触发**：亲戚群像的"信念沉淀"（那孩子回来必定是为了老屋）不必每步都算，按重要性累积触发即可，省成本。
3. **采访式评测移植**：对深雪 agent 跑 25 题人设采访，与人物圣经对照打分——比只测台词正则更接近"角色立没立住"。
4. **成本红线**：它 2023 年一次实验 1000+ 美元；本项目每回合 3–5 次调用的预算设计是对的，离线八卦模拟务必用小模型/规则。
