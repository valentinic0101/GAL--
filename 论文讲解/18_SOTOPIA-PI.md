## 🎯 与 GAL 项目的相关度：7 / 10

它回答了架构 V1 第四节悬而未决的问题：**"用素材文本给深雪做 LoRA 微调"具体怎么做才对？** 它给出了完整管线（合成社交任务 → 专家轨迹 → 自博弈 → 自然语言反馈过滤 → QLoRA），并证明 7B 小模型能追平 GPT-4 的社交表现——这正是"一个大模型演所有角色"降本路线的终局形态。

## 二、论文本身

### 2.1 要解决的问题

SOTOPIA 榜单显示 7B 级开源模型的社交能力远弱于 GPT-4。SOTOPIA-π 要用**自动化的训练管线**把社交技能"练"进小模型，同时不损害通用能力与安全性。

### 2.2 方法：三步训练管线

1. **社交任务生成（SEED）**：从 Social Chemistry / Social IQa / Normbank 抽关键词，由 GPT-4 合成新社交任务（背景 + 目标 + 关系目标）——解决"社交训练数据稀缺"。
2. **行为 rollout**：**行为克隆 BC**（GPT-4 专家在 SOTOPIA 里自对弈的轨迹）+ **自我强化 SR**（被训 agent 自己跟自己博弈，扩展数据）。
3. **社交规划/语言反馈**：用自然语言反馈打磨对话轨迹，GPT-4 按 0–10 目标完成度评分过滤，再 **QLoRA** 微调 7B 基座（初版 LLaMA-2，发布版 Mistral-7B；早期版本表述为 DPO 偏好优化）。

## 三、评价所用的技术

- **环境即基准**：训练后回到 SOTOPIA 环境自动评测（自己的框架自己验收，注意这层循环性）+ **Prolific 平台人类评测**双重验证。
- **关键数字**：BC+SR 组合达到目标完成度 **5.71**，几乎追平 GPT-4 专家 agent 的 **5.89**——7B 模型首次在开放社交任务上接近 GPT-4。
- **通用能力回归**：MMLU 57 科与基座持平（无灾难遗忘）——"专项微调不伤通用"的实证。
- **安全性**：危害预防提升、毒性词减少。
- **方法论发现**：**LLM 评委系统性高估社交特化 agent**——自己人给自己打分的水分要警惕。

## 四、对 GAL 项目的启发

1. **深雪 LoRA 的施工图**：架构 V1 把"素材文本 LoRA"列为最后手段；若真要做，本篇给出顺序：先用大模型 + 人物圣经**合成对演轨迹**（不拿原始素材直接训，量太小）→ 过滤（按圣经 checklist 打分）→ QLoRA。素材文本的作用是做**评测金标准**，而不是直接当训练语料。
2. **BC + 自博弈**：修二 Agent × 深雪 Agent 的 P1/P7 预设对演（阶段 0）天然就是自博弈数据源——对演原型从第一天就在为将来的微调攒数据。
3. **防过拟合与遗忘**：上通用回归集（哪怕只是 MMLU 抽样 + 常识对话集），确保深雪没被调成一问三不知。
4. **评委校准再次警告**：特化之后的模型，自动评委更容易给高分；金标准必须是圣经 checklist + 人工抽检。
