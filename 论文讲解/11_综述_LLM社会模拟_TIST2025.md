## 二、论文本身

### 2.1 覆盖范围

系统梳理"LLM 驱动的社会模拟"，按模拟目标分两级组织：

- **个体层**：如何用 LLM 构造拟人 agent——认知-情感维度、记忆机制、角色扮演/画像能力（细分 zero-shot 人设与数据驱动拟合两类，后者即千人分身式 grounding）；
- **社会层**：agent 社会中的群体行为与社会动态（传播、极化、制度涌现等）。

应用覆盖经济与社会、政治与政策、文化与心理；讨论规模、真实性、评测标准化等挑战与方向。

### 2.2 价值

这是源笔记所列两个综述中**更"社会模拟"专精**的一个（另一个 Xi 2023 是泛 agent 综述）。它把 2022–2025 这条线的论文（Smallville → S³ → OASIS → 千人分身 → AgentSociety）串成了谱系。

## 三、评价所用的技术（综述如何梳理评测）

对写"评价所用的技术"类文档最有用的部分——它把社会模拟的评测方法归纳为：

1. **微宏观模式对齐**：模拟结果与真实世界数据/统计现象对比（信息传播曲线、极化指标、移动模式等）；
2. **人工评估与问卷访谈类验证**：believability 采访、问卷对齐、agent 自述访谈；
3. **干预实验式验证**：在模拟中注入冲击/政策，检验群体响应。

并按"个体对齐 → 群体/社会现象复现"组织各论文的评测实践。领域尚缺统一基准，综述只能罗列做法而无法横向量化比较——这本身就是重要信息：**这个领域还没有标准评测，谁先定义好评测谁就占住方法学高地**。

## 四、对 GAL 项目的启发

1. **项目文档引用库**：架构 V1 里"生成式社交模拟 + 剧情驱动"的判断，引用这篇比引零散论文更省事。
2. **评测 checklist**：把上面三类评测映射到本项目：① 传播曲线对齐（八卦模拟回归测试）② 人设采访人评（阶段 0 验收）③ 干预测试（好感度初值扰动 × 20 次跑分布）。
3. **定位认知**：综述确认"剧情驱动/互动叙事"在社会模拟综述里只是边缘话题——本项目处在两个社区的交界地带，两边的文献都要看（这正是这份合集存在的原因）。
