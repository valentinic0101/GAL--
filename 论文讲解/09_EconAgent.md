## 二、论文本身

### 2.1 要解决的问题

传统计算经济学 ABM 的 agent 是最大化效用函数的规则机器，产生不出"人味"的宏观现象（如通胀预期驱动消费收缩）。论文把 LLM 接入 ABM，让个体决策产生真实的宏观涌现。

### 2.2 方法

agent 三件套 + LLM 决策脑：

- **感知模块**：个体层（储蓄、收入、历史行为）+ 宏观层（通胀、利率、失业率）；
- **记忆模块**：积累并反思过往决策经验，行为随时间自适应演化；
- **LLM 决策**：产出**通胀预期**以及消费-储蓄、劳动-休闲决策。

模拟经济环境中运行多个宏观场景（不同通胀/利率/失业率冲击组合）。

### 2.3 关键结果

- LLM agent 展现更高的个体多样性与更接近真人的行为特征（通胀上升时增加储蓄、下调消费）。
- 宏观层聚合出现实的**通胀预期轨迹**与总量经济现象，验证"个体行为→宏观现象"传导链。

## 三、评价所用的技术

- **基线对比**：与规则驱动 agent 对比个体多样性与宏观轨迹；
- **宏观现象复现**：模拟出的通胀预期/消费行为与经济学理论与现实观察定性对照；
- **局限**：未与真实微观数据（住户调查等）做定量校准，场景为简化封闭经济。

## 四、对 GAL 项目的启发

1. **宏观变量进感知**：小镇也可以有"宏观层"——季节、祭典倒计时、遗产风波的舆论温度。角色感知"最近镇上都在议论老屋"（宏观）而不仅是自己的记忆（个体），行为会更有群体性。
2. **预期的角色**：EconAgent 的核心洞察是"**预期**（对未来的判断）驱动行为"。深雪"预期修二迟早要追问身世"→ 主动回避某些话题——把'预期'作为角色内部状态的一个字段，比只记过去更有戏。
3. 其他方面借鉴价值有限。
